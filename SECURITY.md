# Security Policy

## Reporting a Vulnerability

We take the security of Excalidraw MCP seriously. If you believe you have found a security vulnerability, please do not report it through public GitHub issues or public discussions.

Please report security vulnerabilities confidentially through GitHub Security Advisories:

👉 [Report a security advisory](https://github.com/Dharshan2208/excalidraw-mcp/security/advisories/new)

When reporting a vulnerability, please include:
- A description of the issue and potential impact
- Detailed steps to reproduce or a minimal proof of concept (PoC)
- Environment details (OS, Python version, package version)
- Any proposed mitigations or patches if available

You will receive an acknowledgment of your report and updates as we work to address it.

## Supported Versions

| Version | Supported |
|---|---|
| `0.2.x` | Yes |
| `< 0.2.0` | No |

For full details on the security architecture, write confinement, and live server protections, see [docs/security.md](docs/security.md).
